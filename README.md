# travelassist3

Assist for traveling

## Getting Started

This project is a companion app for traveling.

It will contain features like
- currency converter
- todo list
- keeping track of expenses
- keeping notes
- etc

## Appearance
Open **Settings** from the home screen menu to toggle dark mode. Settings closes
before the theme changes, and the selected mode is saved for the next launch.

## Architecture
Flutter drift database shall be used to store data.
